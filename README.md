# Bedroom studio redesign

Design proposal to turn the current bedroom studio/office into an official dual-zone space: a finished dark producer booth and a soft sleep side.

## Open the board

Open [`design/index.html`](design/index.html) in a browser (local file or any static host).

## Direction

**Moody producer atelier** — keep the matte black envelope, oak sit-stand desk, Adam monitors, MIDI tray, wall guitars, and warm paper lighting. Make it official by finishing the wall, enclosing clothes, and giving the curtain a real threshold job.

## Priority order

1. Repair + repaint the scarred black wall  
2. Hide the open clothes rack (closed wardrobe)  
3. Full ceiling-track charcoal curtain  
4. Three fabric acoustic panels behind the desk  
5. Cable tray + warm bias light

- `design/photos/` — existing room angles  
- `design/concepts/` — generated concept renders from those angles
