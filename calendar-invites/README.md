# Secret Riso Club — July 2026 Calendar Invites

iPhone-ready `.ics` calendar files for the July Events & Workshops flyer.

## Quick start (iPhone)

1. Open **`secret-riso-club-july-2026.ics`** on your iPhone (AirDrop, Files, Messages, or email attachment).
2. Tap **Add All** (or review each event).
3. Choose the calendar to save to.

To add only some events, open files in the `individual/` folder one at a time.
